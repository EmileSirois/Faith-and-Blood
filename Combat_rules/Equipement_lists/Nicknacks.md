### List de nisknacks et divers items variés

| Item     | Utilisation                                                                                                                   | Coût |
| -------- | ----------------------------------------------------------------------------------------------------------------------------- | ---- |
| Menottes | Utilisez une Action pour mettre les menottes sur une créature, la créature doit être incapacitée                              | -    |
| Chaîne   | Utilisez une Action pour enchaîner une créature, la rendant [Restrained](../Conditions.md#restrained) avec un Escape Dc de 12 | -    |
| Ball Bearings | Utilisez une action pour répandre des ball Bearings sur le sol, la surface affectée est un terrain difficile et toute créature bougeant dans la surface doit reussir un ST d'Agilité (12) ou être affecté apr la condition [Prone] | - |
| Lanterne | Utilisez une Action pour lancer une lanterne, et créer une surface enflamée de 15 pieds de diametre. Toute créature se trouvant dans la surface est affecté apr la condition [Burning](../Conditions.md#burning)(1). Lorsqu'une créature commence son tour dans la surface, elle ajoute un tour de Burning. | - |
| Caltrops | Utilisez une Action pour déployer des caltrops et créer une surface de 20 pieds de diamêtre qui devient un terrain difficile. Toute créature se déplaceant dans la surface prend 1d4 piercing Dmg par 5 pieds de mouvement pris dans la surface. | - |
| Bolas | Utilisez une Action pour Faire une Atq contre une cible en utilisant votre Agilité. Si l'atq touche, la cible est [Ensnared](../Conditions.md#ensnared) | - |
| Rage Powder | Utilisez une action pour projeter de la poudre sur une cible. Celle-ci doit reussir un ST d'inteligence (10 + Charisme), sinon quoi elle est forcée de se concentrer sur vous uniquement pour 2 rounds | - |
