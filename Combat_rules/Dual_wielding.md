# règles pour le Dual wielding

### Definition

Le dual Wielding fait référence à l'Action d'équipper deux armes possédant la propriété [Light](./Equipement_lists/Weapon_property_list.md), afin de pouvoir les utiliser en même temps.

### Off Hand Atq

Lorsque vous attaquez avec une arme en Dual Wielding, vous recevez dans votre AP une Action Off Hand Attack, avec laquelle vous devez utiliser exclusivement l'arme dans votre autre main. Cette action peut être utilisée pour effectruer une autre attaque, et peut être utilisée dans une combinaison à la place d'une Attaque Normale. Si vous tentez d'utiliser une combinaison utilisant 2 action Attaquer, vous pouvez utiliser une Action d'attaquer et Off hand Attack, même si vous n'avez pas encore celle-ci dans votre AP.

L'attaque faite avec l'action Off Hand Attack est faite avec votre même modificateur d'Atq, mais le Dmg imfligé par l'arme n'ajoute pas votre modificateur de Charactéristique.
