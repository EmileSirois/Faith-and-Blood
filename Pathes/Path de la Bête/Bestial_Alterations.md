# Modifications Bestiales

### Altérations de Niveau 1 :

| Alteration       | Effet                                                                                                                  |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Crocodile's Hide | Agis comme une armure légère Naturelle avec un Armor Rating de 13.                                                     |
| Owl's Eyes       | Vous avez 1000 pieds de Darkvision, ajoutez +2 à vos checks de Perceptions faits avec vos yeux.                        |
| Crow's Feathers  | Réduis les Dmg de chûte de moitié, Vous donne avantage sur les _Checks_ de Stealth lorsque vous êtes dans l'obscurité. |
| Tiger's Claws    | Vous donne une arme naturelle (1d8, [Rending](../../Combat_rules/Equipement_lists/Weapon_property_list.md))            |
| Viper'S Fangs    | Vous donne un Tour de Force Naturelle : [Venom Bite](../../Combat_rules/Equipement_lists/Tours_de_Force_list.md)       |
| Greyhound's Legs | Augmente votre vitesse de mouvement de 15 pieds                                                                        |
